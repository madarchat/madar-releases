# Madar — app releases

Official builds of the **Madar** mobile app (Flutter). One app, two isolated modes:

- **Personal account** — phone sign-in, private by default, waves, end-to-end encrypted chats, moments.
- **Workspace account** — join your workspace's own self-hosted server ([madar-self-hosted](https://github.com/madarchat/madar-self-hosted)).
